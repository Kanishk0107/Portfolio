# AI/ML & Full-Stack Engineering Roadmap

Study notes, reference blueprints, and technical references.

## 1. Machine Learning & Applied AI

- **Classical ML:** Random Forest, Gradient Boosting, SVM, Feature Engineering, Cross-Validation.
- **Deep Learning:** PyTorch, TensorFlow, Transformer architectures, Embeddings.
- **Decision Intelligence:** End-to-end data pipelines, inference latency optimization, model serialization.

## 2. LLMs & Agentic Systems

- **Tool Use & MCP:** Model Context Protocol tool definitions, schema validation, server/client architecture.
- **Multi-Agent Orchestration:** Agent routing, Socratic gating, delegation, state machines.
- **Prompt Engineering:** Structured JSON outputs, dynamic grounding, chain-of-thought workflows.

## 3. Full-Stack Product Engineering

- **Frontend:** Responsive layout engines, CSS design token systems, Canvas API, WebGL / 3D.
- **Backend & APIs:** Python (FastAPI/Flask), Node.js, RESTful & GraphQL architecture.
- **Deployment & Ops:** CI/CD workflows, static site generation, cloud edge hosting.
