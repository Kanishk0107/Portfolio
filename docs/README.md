# Project Documentation & Learning Hub

This directory serves as the centralized workspace for documentation, technical architecture, and learning resources.

## Structure

```
docs/
├── architecture/
│   └── PORTFOLIO_SYSTEM.md    # Portfolio application design & component specifications
├── learning/
│   └── AI_FULLSTACK_ROADMAP.md # AI/ML, Full-Stack engineering & agentic workflows guide
└── README.md                  # Hub index (this file)
```

## Directory Responsibilities

- **`src/`**: Application source code (CSS stylesheets, JavaScript modules, components).
- **`public/`**: Static public assets served at root (`asset/`, `robots.txt`, `sitemap.xml`, `llms.txt`).
- **`docs/`**: Documentation, learning blueprints, and architectural references.
